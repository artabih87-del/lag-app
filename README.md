# LAG

LAG is a modern platform designed to help people find problems, solutions and professionals.

## Features

- LAG branding and splash screen
- Home feed
- Search
- User profiles
- Professional profiles
- Problems and solutions
- Private messages
- Settings
- Languages
- Location
- Owner/Admin dashboard
- Responsive mobile and desktop design

## Languages

- Arabic
- French
- English

Arabic supports RTL.

## Production integrations

The application is prepared for:

- Supabase Authentication
- Supabase Database
- Supabase Storage
- Supabase Realtime
- Secure AI integration
- Phone verification
- Real-time communication
- Notifications

## Important

External services must be connected securely before production.

Never put private API keys directly inside frontend code.
